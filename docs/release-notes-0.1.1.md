# TorrFrame TV 0.1.1 — local preview

- Fix unreadable text on dark backgrounds by providing the inherited content color.
- Add consistent typography, button outlines, focus borders and selected navigation states.
- Rework the Home onboarding panel, empty Library, Jackett connection screen and grouped Settings.
- Keep the Settings save action visible while scrolling.
- Transfer focus when a content action opens another screen, and direct Down from navigation to the first content action.
- Allow Down from text editors to reach Done/Cancel and handle Escape as Back.
- Enable the development AVD hardware keyboard and keycode forwarding.

This is a development preview. Visual acceptance is performed by the owner;
physical Android TV codec and performance validation remains separate.
