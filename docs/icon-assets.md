# Иконка и TV-баннер: файлы для Photoshop

Android TV использует два отдельных ресурса: квадратную иконку `android:icon`
и прямоугольный баннер `android:banner`. Лаунчер приставки решает, какой ресурс
показывать в конкретном месте. На разных Mi Box, Google TV и сторонних лаунчерах
это может отличаться; оба ресурса должны быть подготовлены.

## Что подготовить

| Файл | Размер исходника | Фон | Содержимое |
|---|---|---|---|
| `icon-foreground.png` | 1024×1024, 1:1 | прозрачный | Только знак; важные детали в центральных 600×600 px |
| `icon-background.png` | 1024×1024, 1:1 | непрозрачный | Фон на весь холст без знака |
| `tv-banner.png` | 1920×1080, 16:9 | непрозрачный | Знак + надпись TorrServe Silicon |

Формат: PNG, цветовое пространство sRGB. Желательно также сохранить PSD со
слоями, чтобы можно было менять расположение знака и фон.

## Скругления и безопасная область

- Квадратные слои не скруглять, не обрезать кругом и не добавлять внешнюю тень
  вокруг границы всей иконки. Маску (круг, squircle, скруглённый квадрат) выбирает
  система или лаунчер. Отдельного универсального радиуса для Mi Box нет.
- Для adaptive icon Android задаёт холст 108×108 dp и консервативную безопасную
  центральную область 66×66 dp. Центральные 600×600 px на мастер-холсте 1024×1024
  помещаются в эту область; декоративный фон может заполнять весь холст.
- Баннер тоже экспортировать прямоугольным, без предварительного скругления.
  Для композиции рекомендуется оставить 5–10% отступа от краёв для знака и текста;
  это дизайнерский запас, а не обязательный размер Android.
- Баннер должен включать название приложения. Имя бренда TorrServe Silicon
  одинаково для RU и EN; при добавлении локализованного текста понадобятся версии
  баннера для соответствующих языков.

Для APK исходный баннер масштабируется до 320×180 px (xhdpi) и остальных
плотностей при необходимости. Минимальная квадратная TV-иконка для xhdpi —
160×160 px. Размеры 1024×1024 и 1920×1080 выше — удобные мастер-файлы для работы,
а не обязательные размеры ресурсов внутри APK.

## Текущие ресурсы preview 0.1.5

Использованы PNG, предоставленные владельцем в `icons/`. Мастер-файлы сохранены
без изменений; таблица показывает их SHA-256 и назначение.

| Исходник | Размер | Назначение | SHA-256 |
|---|---|---|---|
| `square icon.png` | 2000×2000 | `@mipmap/app_icon`: launcher | `1d02b9f84d74abcd29e09b0dd0932d0a7bda1adf260e0be0c3c56e989b86c404` |
| `icon16x9.png` | 1920×1080 | `@drawable/tv_banner`: плитка Android TV | `c3b5c54b51f193cc8b3000d0b4ca7c2ae493dca45819df443e35dc51c6de8fbb` |
| `round icon.png` | 1088×1088 | `@drawable/brand_mark`: шапка приложения | `5c004e4bec14b133af1a462a1f89b9a133feb9f4c6173788511aaeecbcccefeb` |

Отдельный `android:roundIcon` в рекомендациях Android TV deprecated. Используем
обычный квадратный ресурс, а форму и выбор между иконкой/баннером определяет
лаунчер. Это готовые растровые ресурсы, не слои полноценной adaptive icon.
Для adaptive icon в будущем потребуются раздельные знак и фон, описанные выше.

`scripts/prepare-icons.py` (Python + Pillow) преобразует профиль исходников в sRGB
и экспортирует PNG с alpha для mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi. Композиция,
пропорции и прозрачность сохраняются, дополнительные рамки/скругления не вводятся.
Круглая иконка внутри приложения: 32, 48, 64, 96, 128 px.
Квадрат: 80, 120, 160, 240, 320 px. Баннер: 160×90, 240×135, 320×180,
480×270, 640×360 px. Воспроизведение ресурсов:

```sh
python3 scripts/prepare-icons.py
```

Предыдущие временные оригинальный PNG и составной drawable-баннер заменены
предоставленными файлами. Визуальную приёмку выполняет владелец проекта.
