# TorrServe Silicon TV 0.1.9 — themes, focus and film details

Appearance is the final Settings group: scale, language, light/dark theme and a
toggle for the whole navigation footer. Preferences apply and persist immediately.
Light mode uses light surfaces and dark text; focused buttons use #008800 with
white text in both themes. Input actions retain their dimensions and keep focus
borders within their bounds.

TV tabs are Search, Library and Settings; startup and Back return to Library.
A header status dot distinguishes connected, unavailable, failed and transitioning
server states. Native stopping is also reported to Phone Remote.

Film details show a poster on the left and title, synopsis and available metadata
on the right. Manual metadata editing and torrent search actions are removed from
this TV screen. The metadata provider is displayed as OMDB; stored provider IDs
and API contracts retain compatibility. Phone Remote uses the supplied round PNG
for its brand image. See verification.md for functional test evidence.
