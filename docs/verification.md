- Список TorrServe записывается одной SQLite-транзакцией и вызывает одно
  уведомление медиатеки. Сохранены ручные названия/метаданные, время добавления,
  прогресс просмотра и прежние файлы при пустом списке от сервера. Ошибка
  откатывает всю пачку; старый автоматический подбор не заменяет ручной выбор.
- Автосохранение настроек сравнивает поля с подтверждённым снимком: неизменённые
  ключи не шифруются повторно, вложенные настройки не сериализуются заново.
  Синхронный commit и увеличение revision остаются при каждом сохранении.
  Явный save сохраняет полный снимок; после неудачного commit следующий вызов
  также восстанавливает полный снимок. Формат хранения и Keystore alias прежние.
- DNS использует отдельную блокировку для каждого встроенного разрешённого
  хоста и потокобезопасный кеш. Зависший хост не блокирует остальные; список
  доменов, TTL, защищённый DNS, TLS и обработка пользовательских адресов прежние.
- Подбор метаданных блокируется по ключу кеша; независимые фильмы обрабатываются
  параллельно. Сетевых операций по-прежнему максимум две. Ожидание того же ключа
  не занимает второй слот. Сохранены приоритеты, сопоставление и отмена запросов;
  запись блокировки удаляется, когда последний участник выходит.
