# Проверки Android TV

## Preview 0.1.2 — компактный интерфейс и оригинальный брендинг

Дата: 2026-10-12. Debug и R8 Release собраны; 25 JVM-тестов пройдены,
lint: 0 ошибок, 12 предупреждений. 6 UI-тестов пройдены на отдельном Android TV
профиле в двух размерах: 1920×1080 при 320 dpi (960×540 dp) и 1440×810
при 320 dpi (720×405 dp). Проверены вкладки и BACK, переходы с передачей фокуса,
редактор настроек и отмена с восстановлением фокуса, отсутствие ручных magnet
действий, размещение кнопок Home в малой области и светлый цвет текста.

Исходный PNG иконки получен из оригинального GitHub-репозитория; SHA-256 и
требования к будущим Photoshop-слоям описаны в `icon-assets.md`. В APK используются
квадратная иконка и отдельный 16:9 drawable-баннер с именем бренда.

Типографика и отступы уменьшены. Компоновка использует размер окна в dp через
LocalWindowInfo/LocalDensity; на малой области вспомогательная панель Home
скрывается, сетка медиатеки адаптирует число колонок. Диагональ телевизора не
используется как источник размера. Настройки и медиатека ручного профиля не
сбрасывались; UI-тесты выполнялись только на отдельном профиле.

Визуальную приёмку и проверку на домашней Mi Box выполняет владелец проекта.
Computer Use и скриншоты не использовались. Этот этап не заменяет тестирование
аппаратных кодеков и длительного воспроизведения на реальной приставке.

## Preview 0.1.1 — исправления интерфейса и ввода

Дата: 2026-10-12. Android TV API 36 ARM64, 1920×1080; эмулятор 37.3.3,
GPU host на Apple M5 Pro. Аппаратная клавиатура AVD включена.

- Финальная совместная сборка Debug и оптимизированного Release прошла.
- 25 JVM-тестов: 0 ошибок.
- 4 UI instrumentation-теста: 0 ошибок. Проверены настоящие Android-события
  D-pad/Enter/BACK, вкладки и выбранные состояния, переход из Home в Search и
  Settings с переносом фокуса, отмена редактора magnet и возврат фокуса.
- Отдельная регрессия проверяет светлый наследуемый цвет обычного текста
  вне кнопок и Surface.
- Lint: 0 ошибок, 13 предупреждений.
- Preview APK имеет versionName 0.1.1, versionCode 2 и корректную v2-подпись.
- На Mac включены аппаратная клавиатура и keycode forwarding. Escape
  обрабатывается приложением как BACK.
- Поля ввода используют state-based BasicTextField/BasicSecureTextField:
  автоматическая IME отключена при аппаратной клавиатуре, пароли скрыты,
  курсор светлый, DOWN и IME Done передают фокус действиям диалога.
- На macOS изменяемые результаты Gradle вынесены из Documents в Library/Caches.
  В новом каталоге не обнаружены дубликаты файлов вида `… 2.class`/`… 2.xml`.

Визуальную приёмку выполняет владелец проекта. Computer Use и автоматические
снимки экрана не использовались. Текущие проверки не подтверждают аппаратные
кодеки и производительность физической TV-приставки. Backend-интеграционные
проверки 0.1.0 ниже относятся к предыдущей версии; в этом изменении они
не запускались повторно.

# Историческая проверка preview 0.1.0

Дата: 2026-10-12. Разработка и тесты на Mac Apple Silicon. Android TV AVD API 36,
ARM64, 1920×1080, 2 GiB виртуальной RAM, SwiftShader. Computer Use и визуальный
осмотр не выполнялись. macOS worktree остался чистым на исходном commit ac00385.

## Подтверждено выполнением

- Debug и Release компилируются; Release использует R8 и resource shrinking.
- Android lint: 0 ошибок; остаются некритичные предупреждения о стиле API/Compose,
  фиксированной ориентации TV и отдельных строках/версиях инструментов.
- 25 JVM-тестов: названия/годы/эпизоды/двуязычные варианты, namespaces и caps,
  повреждённый XML и частичные результаты, DTD rejection, hash normalization,
  сортировка/дедупликация, HTTP ошибки/лимиты/отмена, reverse proxy и encoding,
  модели TMDB/OMDb/Kinopoisk/AniList, HTTP redirect Jackett → magnet.
- 4 Android instrumentation-теста: SQLite/кеш/история после reopening,
  Android Keystore encryption/reload, настоящий TorrServer + Media3, D-pad/BACK.
- Оригинальный ELF из nativeLibraryDir действительно запускается. `/echo`
  возвращает MatriX.146.1; повторный Start сохраняет PID одного процесса.
- Собственный H.264 ролик добавляется через torrent upload, движок получает
  данные от настоящего локального BitTorrent-сида, Media3 начинает воспроизведение.
  Позиция сохраняется на паузе. После сворачивания поток остаётся активным
  **17 секунд**, то есть дольше 15-секундной задержки остановки idle-сервера.
  Torrent removal удаляет запись без дубликатов. Отдельно проверено восстановление
  утраченной серверной записи при повторном добавлении из поиска: локальная
  запись остаётся единственной, playback history сохраняется.
- Пульт: переходы Home → Search → Library → Settings, BACK → Home с фокусом.
- Оптимизированный preview APK устанавливается и запускается на API 36; native
  API также отвечает после установки minified APK.
- APK Signature Scheme v2 проверена apksigner. Подпись — Android Debug,
  production signing/publishing не выполнялись.
- SHA-256 ELF совпадает с официальным GitHub asset и preBuild проверяет его.
  PT_LOAD alignment у TorrServer и AndroidX graphics library — 16384 байт.
  Это проверка бинарников, не отдельный тест устройства с 16 KiB страницами памяти.
- Проверены class definitions и assets APK: test classes, MockWebServer,
  instrumentation keys и тестовое видео не включены в приложение.

## Первичные измерения оптимизированного preview

Команда `scripts/profile-adb.sh`, пустая библиотека, один AVD. Сырые результаты
сохраняются в `artifacts/profile/`. Cold означает force-stop процесса приложения;
warm — закрытие Activity и повторное создание при существующем процессе.

| Показатель | Один замер |
|---|---:|
| Cold Activity start (`am start -W`) | 119 ms |
| Warm Activity start | 50 ms |
| App PSS | 32,181 KiB |
| App RSS | 137,540 KiB |
| TorrServer RSS | 51,584 KiB |

Эти значения — исходный ориентир, не гарантия для приставки. Стартовый gfxinfo
содержал 22 кадра и 3 janky frames; он не подтверждает 60 FPS при прокрутке
библиотеки с постерами. Для реальной медиатеки, поиска и длительных потоков
нужны отдельные профили. Debug содержит фиксированные latency labels и FrameMonitor.

## Что требует ручной приёмки

1. Визуальный дизайн, размеры, контраст, читаемость с телевизора и локализация.
2. D-pad внутри длинных списков, редакторов/IME, диалогов, файлов и панели дорожек;
   фокус и положение после обновления постеров/сортировки. Код восстановления
   реализован; все визуальные состояния автоматически не проверялись.
3. Существующий Jackett с пользовательскими credentials, конкретные indexers,
   частичные ошибки/HTTPS/reverse proxy и реальные torrent download URLs.
4. Реальные provider API keys, качество метаданных на пользовательской коллекции
   и доступность изображений в конкретной сети. Контракты проверены fixtures.
5. Физическая ARM64 приставка: аппаратный MediaCodec, HEVC/HDR/DTS и другие
   конкретные форматы, длительные фильмы, Wi-Fi, перемотка и RAM под нагрузкой.
6. App updater с настоящим Android TV GitHub Release, production сертификатом,
   системным разрешением установки и полным upgrade cycle. Реальный Android TV
   репозиторий/Release в этой работе не публиковался.

## Этапы

Analysis и foundation завершены, интеграции реализованы и проверены в доступной
локальной среде. Design требует визуальной приёмки пользователя. Performance
пока имеет исходные измерения эмулятора. Release доставлен как локальный preview,
без утверждения о полной приёмке физического устройства или публичной публикации.
